## 2. Core production rules

Let `PROGRAM` be a sequence of `STATEMENT`s.

```text
PROGRAM      → STATEMENT*
STATEMENT    → ALTITUDE_STMT
             | OP_STMT
             | SERIESF_STMT
             | SPECTRAL_STMT
             | INVARIANT_STMT
             | SYSTEM_STMT
             | COMMENT

COMMENT      → "#" TEXT
```

### 2.1 Altitude statements

```text
ALTITUDE_STMT → "altitude" "set" ALTITUDE
               | "altitude" "drop"
               | "altitude" "lock" "spectral"

ALTITUDE      → "narrative" | "structural" | "spectral"
```

### 2.2 Operator statements

```text
OP_STMT       → "op" "apply" OPERATOR IDENT

OPERATOR      → "Drift"
              | "Collapse"
              | "Resonance"
              | "Parity"
              | "restart_safe"
              | "drop_altitude"

IDENT         → /[A-Za-z_][A-Za-z0-9_]*/
```

### 2.3 Series F statements

```text
SERIESF_STMT  → "seriesF" "run"
              | "seriesF" "check"
              | "seriesF" "run" "spectral"
```

### 2.4 Spectral statements

```text
SPECTRAL_STMT → "spectral" "solve"
              | "spectral" "inspect"
              | "spectral" "guardrail" "test" IDENT
```

### 2.5 Invariant statements

```text
INVARIANT_STMT → "invariant" "check" INVARIANT

INVARIANT      → "softness"
               | "altitude"
               | "non_activation"
```

### 2.6 System statements

```text
SYSTEM_STMT   → "system" "zero"
```
