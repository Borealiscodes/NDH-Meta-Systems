## 1. Interpreter Overview

The NDH‑DSL interpreter is a **three‑stage execution pipeline**:

1. **Lexing** — convert raw text into tokens defined in Grammar v1.1  
2. **Parsing** — build an AST using production rules  
3. **Evaluation** — execute AST nodes using NDH operators, altitude morphisms, and spectral functors

This pipeline must preserve:

- altitude discipline  
- zero/identity laws  
- Series F coordination rules  
- spectral ascent safety  
- invariant enforcement

## 5. Zero and Identity Handling

### Zero events

Triggered by:

- `altitude.drop`
