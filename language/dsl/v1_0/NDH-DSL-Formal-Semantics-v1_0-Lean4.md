## 1. Semantic domains

  - **Altitude:** `Narrative | Structural | Spectral | Zero`

\[

## 2. Core evaluation rules (informal Lean style)

Let `⟦stmt⟧` be the semantics of a single statement.

- **Altitude set:**

  - `⟦altitude.set structural⟧ (a, s) = (Structural, s)`  
  - `⟦altitude.set spectral⟧ (Structural, s)` allowed only if Series F invariants hold; otherwise → `Zero`.

- **Altitude drop:**

  - `⟦altitude.drop⟧ (a, s) = Zero`

- **Operator apply:**

  - `⟦op.apply Drift x⟧ (Structural, s) = (Structural, Drift s x)`  
  - `⟦op.apply drop_altitude x⟧ (a, s) = Zero`

- **Series F:**

  - `⟦seriesF.run⟧ (Structural, s) = (Structural, s')` if coordination succeeds; else `Zero`.  
  - `⟦seriesF.run.spectral⟧ (Structural, s)` triggers spectral ascent via locked spectral functor; failure → `Zero`.

- **Spectral:**

  - `⟦spectral.solve⟧ (Structural, s)` → `(Spectral, s')` if guardrail passes; else `Zero`.  
  - `⟦spectral.inspect⟧ (Spectral, s)` leaves altitude unchanged.

- **Invariant check:**

  - `⟦invariant.check softness⟧ (a, s)` → `Zero` if softness violated; else `(a, s)`.

- **System zero:**

  - `⟦system.zero⟧ (a, s) = Zero`.

## 3. Composition rule (program semantics)

For a program `p = [s₁, s₂, …, sₙ]`:

- Base:

  \[
  \llbracket [] \rrbracket (a, s) = (a, s)
  \]

- Inductive:

  \[
  \llbracket s :: p \rrbracket (a, s) =
  \begin{cases}
    Zero & \text{if } \llbracket s \rrbracket (a, s) = Zero \\
    \llbracket p \rrbracket (a', s') & \text{if } \llbracket s \rrbracket (a, s) = (a', s')
  \end{cases}
  \]

Zero is absorbing: once reached, the program terminates.

## 4. Key properties to prove in Lean 4

- **Altitude safety:**  
  Spectral commands (`spectral.solve`, `seriesF.run.spectral`) never execute from `Narrative` altitude.

- **Zero absorption:**  
  If any statement yields `Zero`, the whole program yields `Zero`.

- **Identity preservation:**  
  `restart_safe` does not change altitude and preserves NDH invariants.

- **Spectral correctness:**  
  Spectral ascent/return respects the locked spectral functor chain and Rust guardrail behavior.

These become Lean theorems over the semantics defined above.
