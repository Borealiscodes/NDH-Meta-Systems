## 2. Runtime dashboard blueprint

- **Core panels:**
  - **Altitude Panel:** Shows current altitude (`Narrative`, `Structural`, `Spectral`, `Zero`) and transition history.  
  - **NDHState Panel:** Displays S16 snapshot and invariant flags (softness, altitude, non‑activation).  
  - **Functor Trace Panel:** Lists recent functor calls (`F_eval`, `F_S`, `F_spec`, `F_alt`, meta‑functors) with timestamps.  
  - **Spectral Pipeline Panel:** Shows current stage (Lean, JSON, FEniCS, Rust) and guardrail status.  
  - **Zero/Identity Events Panel:** Logs zero events, identity events, and their originating statements.  
  - **Series F Panel:** Shows coordination status and invariant checks per run.

- **Dashboard signals:**
  - **altitude_state:** current altitude.  
  - **ndh_state_hash:** hash of NDHState for quick comparison.  
  - **functor_call_stream:** live feed of functor invocations.  
  - **spectral_stage:** current spectral pipeline stage.  
  - **meta_functor_wrappers:** active meta‑functors on each functor.  
  - **zero_event_counter / identity_event_counter:** counts per session.
