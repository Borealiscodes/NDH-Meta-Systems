## **5.1 — Definition**
**Integration** is the semantic process that:

- binds **states** (3.1)  
- binds **constraints** (3.2)  
- binds **spectral configurations** (3.4)  
- binds **charts** (3.5)  
- binds **topology** (3.6)  
- binds **admissibility** (3.3)  
- binds **error semantics** (4)  

into a **single coherent semantic structure**.

Integration is the **semantic unification layer**.

---

## **5.2 — Semantic Meaning**
Integration semantics determine:

- how semantic layers combine  
- how transitions propagate across layers  
- how errors influence integration  
- how admissibility gates integration  
- how topology and charts unify spectral structure  
- how constraints shape global behavior  

Integration is the **semantic convergence point**:

```
State → Admissibility → Error → Integration → Serenity Hooks
```

## **5.3 — Integration Components**

### **Layer Binding**
Defines how semantic layers attach to one another.

### **Cross‑Layer Compatibility**
Ensures that:

- constraints  
- spectral fibers  
- chart transitions  
- topological neighborhoods  
- state structures  

remain compatible when integrated.

### **Integration Envelope**
The global structure formed by integrated semantic layers.

### **Integration Transitions**
Transitions that propagate across multiple semantic layers simultaneously.

## **5.4 — Integration Validity Rules**
Integration is **valid** when:

- all layers are individually valid  
- cross‑layer compatibility holds  
- transitions preserve reversibility  
- transitions preserve drift‑neutrality  
- transitions preserve altitude bounds  
- transitions preserve membrane neutrality  

Integration is **invalid** when any rule fails.

Invalid integration triggers **error semantics** (Section 4).

---

## **5.5 — Integration Propagation Rules**
Integration propagates through:

- state transitions  
- spectral transitions  
- chart transitions  
- topological transitions  
- admissibility transitions  
- error transitions  

Propagation must:

- preserve reversibility  
- preserve drift‑neutrality  
- preserve altitude bounds  
- preserve membrane neutrality  

Propagation must **not** activate runtime or solver layers.

## **5.6 — Integration Resolution Semantics**
Resolution may:

- refine layer bindings  
- adjust compatibility rules  
- repair transitions  
- revalidate layers  
- re‑evaluate admissibility  
- reclassify errors  

Resolution must be:

- reversible  
- drift‑neutral  
- altitude‑bounded  
- membrane‑neutral
