# ⭐ **3 — Temporal Components (v2.4)**

## **TG‑1 — Epoch Geometry**
Governance epoch geometry must remain:

- **flat**  
- **non‑recursive**  
- **non‑stacking**  
- **non‑branching**

Epoch formation is **forbidden** at G0.

## **TG‑2 — Temporal Load**
Temporal load must remain:

- **zero**  
- **non‑accumulating**  
- **non‑reflective**  
- **non‑propagating**

Governance cannot carry temporal weight.

## **TG‑3 — Temporal Reflection Boundary**
Reflection is allowed only as:

- **first‑order reflection**  
- **non‑recursive**  
- **non‑curved**  
- **non‑elevated**

Second‑order reflection is **forbidden**.  
Third‑order reflection is **sealed‑layer only** (A12).

## **TG‑4 — Temporal Traversal Geometry**
Traversal must remain:

- **linear**  
- **non‑branching**  
- **non‑accelerating**  
- **non‑decelerating**

Traversal cannot:

- skip  
- invert  
- recurse  
- loop  

## **TG‑5 — Temporal Return‑Path Invariants**
Every transition must include:

- **forward path**  
- **reverse path**  
- **neutral path**  

Return‑paths must be:

- drift‑free  
- curvature‑free  
- load‑free  

## **TG‑6 — Temporal Adjacency**
Allowed:

- governance ↔ governance  
- governance ↔ rendering (read‑only)  
- governance ↔ construction (provenance‑only)

Forbidden:

- governance ↔ constitutional altitude (A12)  
- governance ↔ sealed‑layer recursion  
- governance ↔ PRECL collapse geometry
