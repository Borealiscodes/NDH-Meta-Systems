The Requirements Map defines the **mandatory constraints**, **structural expectations**, and **governance‑safe boundaries** for State Machine v2.2.  
It ensures v2.2 remains:

- altitude‑correct  
- membrane‑sovereign  
- translation‑only  
- non‑authority

- constellation‑compatible

# 🜁 **1 — Altitude Requirements**

### **R1 — Governance Spine Altitude (G0)**  
v2.2 must remain strictly at **G0**, the governance‑skeleton altitude.

### **R2 — No NDH Altitude Imports**  
v2.2 cannot import:

- NDH membranes  
- NDH curvature  
- NDH holonomy  
- NDH constellation geometry  
- NDH routing logic  
- NDH invariants (A13/A14)

### **R3 — Translation‑Only Interaction**  
v2.2 may interact with NDH systems **only through Treaty Nexus (A0)**.

### **R4 — No Altitude Elevation**  
v2.2 cannot elevate above G0 or collapse into A0.

# 🜁 **2 — Structural Requirements**

### **R5 — Modular Spine Architecture**

- Altitude & Membrane Module  
- Geometry & Palette Module  
- Symbolic & Gradient Module  
- Herd Adjacency Module  
- Traversal & Temporal Module  
- Construction Suite Binding Module  
- Metadata & Lineage Module

### **R7 — No Monolithic Behavior**  
v2.2 must remain decomposed; monolithic governance is prohibited.

- non‑collapsing

Temporal reflection must not:

- distort NDH epochs  
- create temporal load  
- collapse temporal lanes
