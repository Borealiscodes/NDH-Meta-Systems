# 🜁 2 — Core Principles of v2.2  
### **A — Dormant Governance**  
v2.2 governs without activating.  
It defines rules, not behaviors.

### **B — Expressive Safety**  
All transitions must remain within expressive‑safe boundaries.  
No node may enter unstable geometry.

### **C — Multi‑Herd Adjacency**  
v2.2 supports multiple “herds” (conceptual clusters) that may:

- align  
- diverge  
- cross‑reference  
- remain dormant  

without collapsing into each other.

### **D — Temporal Geometry**  
Time is treated as:

- non‑linear  
- altitude‑dependent  
- reversible  
- non‑activating  

This prevents runaway temporal drift.

### **E — Return‑Path Invariants**  
Every transition must include a guaranteed safe return path.  
No state may become orphaned.

# 🜁 4 — State Definitions (Draft)  
### **State A — Dormant Root**  
The initial state.  
All hyperstructures begin here.

### **State B — Structured Dormancy**  
A dormant state with defined adjacency rules.

### **State C — Expressive Boundary**  
A safe boundary state preventing drift.

### **State D — Multi‑Herd Alignment**  
Allows parallel conceptual herds to align without merging.

### **State E — Temporal Reflection**  
A reversible temporal geometry state.

### **State F — Return‑Path Anchor**  
Guarantees safe reversion to State A or B.

### **State G — Expansion Pre‑Gate**  
Locked until governance spine is complete.

# 🜁 5 — Transition Rules (Draft)  
### **Rule 1 — A → B (Dormant Root → Structured Dormancy)**  
Allowed only when adjacency rules are defined.

### **Rule 2 — B → C (Structured Dormancy → Expressive Boundary)**  
Allowed when expressive‑safe limits are established.

### **Rule 3 — C → D (Expressive Boundary → Multi‑Herd Alignment)**  
Allowed when herd definitions are stable.

### **Rule 4 — D → E (Multi‑Herd Alignment → Temporal Reflection)**  
Allowed when temporal geometry is altitude‑safe.

### **Rule 5 — E → F (Temporal Reflection → Return‑Path Anchor)**  
Mandatory before any upward transition.

### **Rule 6 — F → G (Return‑Path Anchor → Expansion Pre‑Gate)**  
Locked until v2.2 is fully ratified.

### **Rule 7 — Any → A (Return to Dormant Root)**  
Always allowed.  
This is the constitutional safety invariant.
